# 架构和概念

Fluxon 是分布式 KV Cache 与 RPC 数据面。KV master 负责成员和元数据协调；owner client 提供共享内存或 SSD 后端容量；external client 通过 RPC 和点对点传输访问数据。

## 核心角色

- **KV master**：成员、路由和生命周期协调。
- **Owner client**：提供缓存容量并处理本地及远端 KV 操作。
- **External client**：接入已有 KV 服务，不贡献容量。
- **RPC**：运行在 KV 传输之上的类型化用户 RPC。
